## 4.0.0

- Complete rewrite based on latest [mumuy/relationship](https://github.com/mumuy/relationship)
- New features: `target` parameter, `pair` type, `optimal` mode, natural language expression parsing
- New API: `relationship()`, `relationshipFromExpression()`, `setRelationshipMode()`
- Greatly expanded relationship data (branch, prefix, multiple, pair, sort, input)
- Support for regional modes (e.g., guangdong, north)
- Support for age/ranking (e.g., 二舅, 大伯)
